# Contributing to EmberWolf Games projects

Thank you for contributing.

## Development flow

1. Work from a short-lived branch.
2. Keep changes focused and reviewable.
3. Never commit secrets, credentials, tokens, private keys, or local `.env` files.
4. Run the repository's documented build, test, lint, and validation commands before opening a pull request.
5. Open a pull request into `main` rather than pushing directly to `main` when repository rules require it.

Repository-specific instructions take precedence over these organization defaults.
